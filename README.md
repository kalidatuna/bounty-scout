# Bounty Scout

A tool for evaluating open-source development opportunities and GitHub issue bounties.

The goal is to quickly identify issues that are:

- still open
- actively maintained
- low competition
- clearly specified
- realistically testable
- worth the implementation time

## Planned features

- GitHub issue analysis
- Repository activity checks
- Competing PR detection
- Contribution policy detection
- Bounty/reward tracking
- Opportunity scoring
